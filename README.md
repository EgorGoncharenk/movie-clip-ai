# Movie Clip AI

**Из длинного видео — в короткие вертикальные ролики с субтитрами.**

Личный проект Егора, созданный с помощью ИИ-ассистента. Приложение объединяет
готовые инструменты распознавания речи и обработки видео в локальный конвейер
с настольным интерфейсом и командной строкой.

**Стек:** Python · PySide6 · FFmpeg · faster-whisper · OpenCV · PySceneDetect.

## Как устроено

```text
Локальное видео → метаданные и аудио → распознавание речи
                → анализ сцен и кандидаты → отбор без повторов
                → кадрирование 9:16 + субтитры → MP4 + отчёт
```

- `app/pipeline.py` связывает этапы обработки.
- `app/services/` содержит распознавание, анализ сцен, отбор и экспорт.
- `app/gui.py` и `app/cli.py` дают два способа запуска.
- `tests/` проверяет настройки, таймкоды, отбор, субтитры и медиаконвейер.

**Проверка 6 сентября 2026:** 38 тестов успешно пройдены на Windows в рабочем
окружении проекта. В набор входит FFmpeg smoke-тест с синтетическим видео.
Это локальная проверка; работа на других конфигурациях отдельно не проверена.

## Возможности

Локальный Windows CLI для подготовки коротких вертикальных роликов из длинных
видеофайлов. Программа не скачивает видео из интернета и должна использоваться
только для материалов, на обработку которых у пользователя есть права.

Реализованы проверка окружения, FFprobe-метаданные, кешируемая транскрибация
faster-whisper, анализ монтажных сцен, автоматическая оценка речевых фрагментов,
удаление пересечений, вертикальный `blurred_background`, SRT/ASS с группами
по 2-3 слова, аппаратный NVENC с CPU fallback, плавное отслеживание лиц внутри
плана, покадрово точные защищённые склейки, MP4, JSON/CSV-отчёты, benchmark
и приложение PySide6.

## Требования

- Windows 10/11 x64.
- Python 3.11.
- FFmpeg и FFprobe со встроенным фильтром `subtitles`/libass.
- От 10 ГБ свободного места для комфортной работы.
- NVIDIA GPU необязательна: Whisper и экспорт автоматически переходят на CPU.

Официальные страницы установки:

- [Python 3.11.9](https://www.python.org/downloads/release/python-3119/)
- [FFmpeg](https://ffmpeg.org/download.html)
- [Windows-сборки FFmpeg](https://www.gyan.dev/ffmpeg/builds/)
- [Git for Windows](https://git-scm.com/install/windows.html)

Ollama и облачные API не требуются. Анализ сцен выполняется локально.

## Установка

В PowerShell из папки проекта:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup_windows.ps1
```

Либо вручную:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -r requirements-cuda.txt
.\.venv\Scripts\python.exe -m app.cli doctor
```

При первой транскрибации faster-whisper автоматически скачает выбранную модель.
По умолчанию используется локальная `medium`. Скрытое скачивание моделей во
время обработки отключено, чтобы приложение не зависало на сетевых запросах.
Файл `requirements-cuda.txt` нужен владельцам NVIDIA GPU; без него программа
автоматически использует CPU.

## Быстрый запуск

### Приложение

Запустите двойным щелчком файл `Movie Clip AI.bat`. Откроется окно без консоли.
Выберите фильм, количество роликов, минимальную и максимальную длительность,
модель Whisper и нажмите «Запустить». Режим «Автоматически выбирать моменты»
включён по умолчанию. Видео также можно перетащить прямо в окно.

Альтернативный запуск из PowerShell:

```powershell
.\run_gui.ps1
```

### Командная строка

Положите локальное видео в `input` и сначала проверьте его:

```powershell
.\run_cli.ps1 inspect ".\input\video.mp4"
```

Автоматический сценарий:

```powershell
.\run_cli.ps1 run ".\input\video.mp4" `
  --clips 3 `
  --min-duration 20 `
  --max-duration 60 `
  --language ru `
  --whisper-model small `
  --quality balanced `
  --encoder auto
```

Допустимо до 20 клипов. Режимы качества: `fast`, `balanced`, `quality`;
кодировщики: `auto`, `nvenc`, `cpu`. Режимы кадрирования: `smart`, `center`,
`blurred`.

Контрольный замер полного конвейера:

```powershell
.\run_cli.ps1 benchmark ".\input\video.mp4" --clips 1
```

Таблица времени, RAM/GPU и `benchmark.json` сохраняются рядом с результатом.

Для ручного режима передайте один или несколько параметров `--clip`. Интервал
принимает секунды, `MM:SS` или `HH:MM:SS.mmm`. Исходный файл никогда не
изменяется и не удаляется.

Раздельный процесс:

```powershell
.\run_cli.ps1 transcribe ".\input\video.mp4" --language ru
.\run_cli.ps1 render ".\input\video.mp4" `
  --transcript ".\temp\video_XXXXXXXX\transcription.json" `
  --clip "70-100"
```

Все параметры:

```powershell
.\run_cli.ps1 --help
.\run_cli.ps1 run --help
```

## Результат

Каждый запуск создаёт новую папку и не перезаписывает предыдущий результат:

```text
output/
  video_20260723_143000/
    report.json
    report.csv
    clip_01/
      clip_01.mp4
      clip_01.srt
      clip_01.ass
      clip_01.json
      preview.jpg
```

Транскрипция кешируется в `temp/<имя>_<сигнатура>/transcription.json`.
Сигнатура учитывает полный путь, размер и время изменения исходника. Флаг
`--overwrite` пересоздаёт кеш. Временный WAV удаляется после успешной команды
`run`, если не передан `--keep-temp`.

## Конфигурация

Основные параметры находятся в `config.yaml`:

- `paths`: входная, выходная и временная папки;
- `transcription`: модель, язык, устройство, тип вычислений;
- `candidate_generation`: длительность, отступы и границы речевых фрагментов;
- `selection`: количество, допустимое пересечение и сходство текста;
- `subtitles`: шрифт, оформление, нижний отступ, число слов в группе и
  максимальная пауза между словами;
- `encoding`: разрешение, кодеки, CRF, preset и сила размытия;
- `logging`: уровень и файл журнала.

Для другого файла конфигурации передайте `--config путь.yaml`. Системный шрифт
должен быть установлен в Windows; сторонние шрифты проект не распространяет.

## Диагностика и типичные ошибки

```powershell
.\run_cli.ps1 doctor
```

- `FFmpeg not found`: перезапустите PowerShell после установки или добавьте
  каталог `bin` FFmpeg в пользовательский `PATH`.
- `no subtitles filter`: установите essentials/full build FFmpeg с libass.
- `CUDA ... cannot access`: запустите с `--device cpu`. CUDA ускоряет Whisper,
  но не обязательна.
- Ошибка загрузки Whisper: проверьте интернет при первом запуске и свободное
  место в `temp/models`.
- Медленная работа: начните с `small`, `--quality fast` и `--encoder auto`.
- Если NVENC недоступен, программа автоматически повторит экспорт через CPU.
- Кириллица и пробелы в путях поддерживаются; передавайте пути в кавычках.

Логи сохраняются в `logs/movie_clip_ai.log`.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m pytest
```

Smoke-тест генерирует собственное короткое видео через FFmpeg, рендерит его в
9:16 и проверяет видео, звук, SRT, превью и отчёт. Чужие видео не используются.

## Ограничения текущей версии

Выбор моментов выполняется локальной эвристикой по транскрипции и монтажным
границам. Это оценка потенциала удержания, а не объективное предсказание
вирусности. Smart reframe плавно сопровождает героя внутри исходного плана,
покадрово уточняет границу и защищает стык чистыми кадрами до прямого перехода.
Это исключает пустые края и короткие смазанные фрагменты между планами, не
сдвигая звук и субтитры. Точное определение говорящего по движению губ, auto
zoom и динамическая подсветка отдельных слов находятся в следующих этапах.
